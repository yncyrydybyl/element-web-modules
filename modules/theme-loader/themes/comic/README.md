# comic: Comic Sans Party

Six variants from "Comic Sans on a Friday" up to "readability is not a goal". The design intent is in
`docs/styleguides/comic.md` and the data in `docs/styleguides/comic.json`.

Status: phase A. `themes.json` lists `shared.css` and `<variant>.css`, but those files are written in phase B.

## Font strategy

Proprietary system faces are only named in the `font-family` stacks and never bundled. Each one has a bundled
free fallback with matching metrics or a similar look:

| Wanted (system, `local`) | Bundled fallback | Why |
|---|---|---|
| Comic Sans MS | Comic Relief 400/700 | metric-compatible clone, so line breaks match |
| Impact | Anton | condensed poster grotesque for WordArt |
| Times New Roman | Tinos 400 / 400 italic / 700 italic | metric clone; GeoCities timestamps and gold WordArt |
| (code) | Comic Mono 400/700 | Comic-Sans-style monospace |

Stack: `"Comic Sans MS", "Comic Relief", "Comic Neue", "Chalkboard SE", cursive`. Users with Comic Sans MS
installed see the real face. Everyone else gets Comic Relief with identical metrics. `--cpd-font-family-sans/mono`
must be set with `!important` (FontWatcher sets them inline).

## Notes for phase B

- Selectors checked against v1.12.33: date separator = `[class*="_timelineSeparator_"] > hr` (shared-components,
  hashed), unread badge = `[class*="_notificationBadge_"]` (forced `cpd-theme-light`, so set tokens on
  `[class*="cpd-theme-"]` too), room list rows = `.mx_RoomListItemView` / `[class*="_roomListItem_"]`, sender
  colour = `.mx_Username_color1..6` (drives the 6 per-sender WordArt styles).
- Composer placeholder: Element sets `--placeholder` inline. Override it with
  `--placeholder: "Sign my guestbook!" !important` on `.mx_BasicMessageComposer_input`.
- Reduced motion: GIF backgrounds have to be swapped for the static PNG/first frame by CSS under
  `prefers-reduced-motion: reduce`. A CSS animation kill switch does not stop GIFs.
- comic-unreadable needs a loader call to switch themes (PANIC button, warning dialog "take me back"). Ask the
  loader agent for `ctx.api.switchTheme(id)` or similar.
