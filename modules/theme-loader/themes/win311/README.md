# win311 — Windows 3.11 theme family

Style guide: `docs/styleguides/win311.md` (human) and `docs/styleguides/win311.json` (data).
Reference captures: `docs/styleguides/refs/win311/`.

## Files

| Path | What |
|---|---|
| `themes.json` | manifest, 7 variants (CONTRACT §2). CSS files are created in phase B |
| `assets/*.woff2` | bundled fonts (see licences below) |
| `assets/*.svg` | pixel-art chrome and icons, generated by `tools/make-assets.py` (original artwork, CC0) |
| `assets/licenses/` | full licence texts of the bundled fonts |
| `tools/make-assets.py` | regenerates every SVG in `assets/` |
| `tools/gen-styleguide.py` | source of truth for `docs/styleguides/win311.json` and `themes.json` palettes/tokens. Re-run it after you change a palette, then re-apply any hand edits you made to `themes.json` (css lists, tokens) |

Proprietary fonts are only referenced with `local()` and are never bundled: `MS Sans Serif`, `System`, `Fixedsys`.
In practice browsers cannot use the .FON bitmap originals, so the bundled fonts carry the look.
Not bundled on purpose:
- The 98.css "Pixelated MS Sans Serif" is a derivative of Microsoft's bitmap and its licence is unclear.
- Fixedsys Excelsior has unclear terms.

Rendering rules:
- `-webkit-font-smoothing: none`
- sizes in 16px steps
- `image-rendering: pixelated` on bitmaps

## Images

Every SVG is original pixel art made for this project (CC0). The chrome follows the Windows 3.1 `VGA.DRV` OBM_* geometry:
- frame: 1px black
- highlight: 1px white on top and left
- shadow: 2px `#808080` on bottom and right
- pressed: 1px grey on top and left only, with the glyph moved +1,+1

## Known gaps / notes for phase B

- The room list is virtualised, so there is no wrapping icon grid. Rooms are 32px program items in a single column. Spaces get the real icon strip.
- The MDI frames, title bars and menu bar come from the enhancer. Without it, the CSS-only fallback draws title bars with `::before` on `.mx_LeftPanel`, `.mx_RoomHeader` and `.mx_RightPanel`.
- The daylight dusk phase (Plasma Power Saver) forces the title text to white. The scheme's black-on-navy is about 1.3:1.
- Leather uses dark windows. The original scheme keeps `Window` = `#FFFFFF`.
