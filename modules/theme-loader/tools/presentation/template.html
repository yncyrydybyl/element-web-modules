Element Theme Atlas

Every theme we're building for Element Web: what it looks like, how far it can go, and how each part of the interface gets styled. Each card shows a screenshot of the real theme, running on element.datanauten.de's Element Web 1.12.33 with the theme loader module.

How it works

Three layers, one module

Element's built-in custom_themes can only change colours and one font. A theme-loader module goes further: Element ships all of its CSS inside cascade layers, so our plain stylesheet overrides any Element rule without fighting specificity.

Layer 1 · tokens

Colour and type

About 120 Compound --cpd-* tokens set from 12 seed colours. Covers most of the modern UI, including the badges Element forces into light mode.

Layer 2 · stylesheet

Shape, texture, layout

Unlayered CSS scoped to html[data-tl-theme]: bevels, sketch borders, LCARS elbows, grid re-layouts, fonts bundled with the module (production only allows self-hosted fonts).

Layer 3 · enhancer

Overlays and behaviour

Optional script per family: Win 3.11 title bars, LCARS frames, marquees, the daylight clock. It adds its own elements next to Element's and never moves the ones Element's React code owns.
