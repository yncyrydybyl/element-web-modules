# element-web-themes

~65 themes for Element Web, delivered by a **theme-loader** Element module (no fork), deployed to
https://element.datanauten.de.

Families: Microsoft Teams · Windows 3.11 · KDE Plasma/Qt · Comic Sans party · Hand-drawn sketch · LCARS ·
Enlightenment · Low-UI paper · Crossovers — each in stages (pure → usable / exciting, past / future, comic /
cyberpunk) and modes (light / dark / daylight following the local clock).

| Path | What |
|---|---|
| `research/` | Theme-system analysis, infra/deploy, style dossiers |
| `docs/CONTRACT.md` | Theme authoring contract (binding) |
| `docs/CATALOG.md` | All variants with stage, mode, seriousness/hype |
| `docs/styleguides/` | Style guide per family (md + json) |
| `loader/` | The theme-loader module, build, dev server |
| `themes/<family>/` | Manifests, CSS, enhancers, assets |
| `tests/` | Fixtures, screenshot/walkthrough/edge-case harness |
| `recordings/` | Screenshots, walkthroughs, comparison grids |
